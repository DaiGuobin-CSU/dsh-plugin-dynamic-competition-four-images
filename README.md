# 动态竞争-四象模型 Skill (dsh-plugin-dynamic-competition-four-images)

基于动态竞争理论构建的 DSH（DeepSeek Harness）插件，经过以“四象模型”为框架的改进，提供强大的六维动态竞争评分能力。

## ✨ 核心功能

- 新增 `dynamic_competition_four_images` 工具。
- 提供六维动态竞争评分。
- 包含 AMC 张力分析、多点克制逻辑与八项自检机制。

## 🚀 安装方式

### 方式一：通过包名直接安装（推荐）
1. 在 DSH 的插件页面点击 **“+ 添加插件”**。
2. 在输入框中输入包名：dsh-plugin-dynamic-competition-four-images
3. 点击 “**安装**” 后再点击“**启用**”，然后退出DSH，再重启DSH，即可使用。

### 方式二：通过自定义插件市场安装

1. 在 DSH 中开启 “自定义插件市场”。
2. 进入 “发现” 页面，添加索引源 URL：
https://rootandsource.github.io/dsh-plugin-dynamic-competition-four-images/plugin-index/index.json
3. 搜索 “**动态竞争**” 或 “**四象**”，点击卡片即可安装。
